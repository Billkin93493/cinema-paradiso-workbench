# 新天堂电影院 · 导演工作台

## 当前版本

0.9.0，macOS 13+ / Apple Silicon 内部测试版。项目已于 2026-10-23 从原私有开发目录整理为独立公开副本，采用维护者选择的 MIT 协议。

## 产品边界

面向导演与影视学生，支持完整电影、广告和短片的个人拉片、手工修正、导演笔记与资料沉淀。原片留在本机，只接受本地影片；不提供影视资源搜索、下载、受保护视频解析、制片管理或团队协作。

## 已有实现

本地影片与分类、播放器、自动切镜、代表静帧、人工切点校正、基础画面识别、已有字幕读取与对白校正、可选云端字幕提取、导演笔记、静帧与片段收藏、标签检索、灵感板、结构画板、PDF / Excel / 静帧包导出，以及本地备份与合并恢复。

“轻账号”只在本机保存昵称和邮箱；没有正式云端注册、登录和备份。历史 DeepSeek 翻译代码与本机 OCR 代码仍保留，但不是当前主入口。

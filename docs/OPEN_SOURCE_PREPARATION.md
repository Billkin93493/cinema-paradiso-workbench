# 公开副本整理记录

日期：2026-10-23。

从已有 0.9.0 项目中保留原生源码、共用界面、报告源码、既有测试、图标、演示素材，以及 Electron 外壳及锁文件。原始文件保持不变，本目录是独立公开副本。

未纳入公开仓库的内容：

- `.tools/`、`node_modules/`：本机运行时和已安装依赖。
- `dist-native/`：多个旧应用、DMG 与 PKG。
- `tmp/`：缓存、浏览器配置、真实影片测试静帧、兼容副本与测试输出。
- `output/` 中的历史 PDF：可重新生成的演示导出。
- 原 `PROJECT.md` 与 `AGENTS.md`：含私人路径和内部协作历史，公开版不含这两个文件，只在 docs/STATUS.md 记录可公开状态；原件仍在原目录。
- `clip-ui-preview/`、`todo-preview/`：历史方案页面，与当前程序运行无关。
- `macos/Tools/ffmpeg`：没有配套来源、构建配置与许可材料的二进制。

维护者明确选择 MIT，并确认现有演示图片可以公开。保留测试中明确标识的虚构样例密钥，它们不是可用凭据。对公开副本进行凭据样式、私人路径、文件类型与构建依赖检查；这不构成全量安全审计。

开源整理仅调整文档、忽略规则与打包范围，不重新设计产品界面，也不重新实现核心功能。
